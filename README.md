#movie-analysis
movie data analysis project using Python, PostgreSQL,  and Power BI.
This project focuses on analyzing movie data using Python, PostgreSQL, and Power BI to explore data and gain meaningful insights.

Tools & Technologies

* Python
* PostgreSQL (SQL)
* Power BI

Project Files

* matches_analysis (1).ipynb — Python notebook for data analysis.
* SQL_matches.sql — SQL queries for data analysis.

Project Objectives

* Analyze and explore data using Python and SQL.
* Practice data cleaning and querying.
* Develop data analysis skills.
* Present meaningful insights from data.

 Key Learnings

* Working with datasets using Python.
* Writing SQL queries in PostgreSQL.
* Understanding data analysis workflows.
* Learning how data can support decision-making.

 Author

Created as a data analysis learning project.
